WiFi Smart Appliance Controller with Power Status Feedback

A WiFi-enabled controller that switches AC appliances ON/OFF remotely through the Blynk app and shows the current power status.

Components

Arduino Uno, ESP8266, relay module, Blynk IoT platform

How it works

1-2 line me batao: app se command jaati hai, ESP8266 receive karta hai, Arduino relay ko switch karta hai, aur status app me wapas dikhta hai.
